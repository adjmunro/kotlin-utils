AsyncDelegate

class AsyncDelegate<out T> : ReadOnlyProperty<Any?, T>

A delegate to asynchronously initialise a property from a suspend function. Backed by Deferred, this delegate handles the async/await operation.

Note: getValue is a blocking operation!
